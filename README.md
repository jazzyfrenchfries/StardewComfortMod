This is a mod I have created for fun for the game Stardew Valley on Steam. To use this mod, simply download and use the Stardew Valley WIKI on how to add mods to your game:)
To setup the mod, I used the Stardew Valley WIKI on how to setup mods, I have also used AI to understand the different usages of features within the Stardew Valley code. 
I use the Better Game Menu API mod to create my custom menu tab.
I use the GenericModConfigMenu (https://www.curseforge.com/stardewvalley/mods/generic-mod-config-menu) for my settings menu.

Included in this mod so far:
- Energy reminder at 25%
- Festival and Birthday reminders on the day specified in settings (automatically the day of)
- Weather reminders in the pause menu.
